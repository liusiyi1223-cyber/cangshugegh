# 产品：互联网总收藏夹

## 一句话定位

一个**私人收藏管理网站**：用户把分散在 B站、小红书、抖音、知乎、微博、百度、微信、YouTube 等平台看到的视频/文章，集中收藏到一个地方统一管理。纯私人工具，无社交功能。

## 核心功能清单

### 1. 账号与登录
- 邮箱 + 密码 注册、登录、退出
- 每个用户的收藏数据**完全私有隔离**（互不可见）

### 2. 收藏内容（核心功能）
- **一键收藏**：用户把平台的"分享文本"粘贴进输入框，系统自动完成：提取链接 → 还原短链 → 识别平台 → 抓取**标题、封面图、作者** → 保存
- **手动添加**：抓取失败时（有些平台反爬），用户可以手动填「链接 + 标题」保存
- **自动去重**：同一个视频不会重复收藏

### 3. 支持 9 个平台
B站、知乎、小红书、抖音、微博、百度、微信公众号、微信视频号、YouTube

### 4. 收藏夹（文件夹，多对多）
- 新建、重命名、删除收藏夹
- 一个收藏**可以同时放进多个收藏夹**
- 顶部有收藏夹栏，可点选过滤：「全部」「未分类」「某个收藏夹」
- 删除收藏夹时，收藏本身不删除（自动变"未分类"）

### 5. 标签
- 给每个收藏打多个标签
- 标签显示在收藏卡片上

### 6. 搜索
- 按标题模糊搜索

### 7. 失效标记
- 手动把某条收藏标记为「已失效」（比如视频被删了），可恢复
- 失效项视觉上置灰 + 划线

### 8. 删除
- 删除单条收藏（带确认弹窗）

### 9. 书签小工具（浏览器端）
- 一段可拖到浏览器书签栏的"小书签"，在任意视频页点一下，自动跳转到本网站并填好链接

### 10. 抓取成功率统计（开发者用）
- 后台记录各平台的抓取成功/失败次数

## 现有页面

1. **登录/注册页**：邮箱 + 密码表单，登录/注册切换
2. **收藏页（主界面）**：所有功能都在这一个页面里

## 每个"收藏"卡片显示的信息

- 封面图（缩略图）
- 标题（可点击跳转到原链接）
- 来源平台（如 bilibili / 知乎）+ 作者
- 所属收藏夹（蓝色小徽章，可删）
- 标签（灰色小徽章）
- 操作按钮：加标签、加收藏夹、标记失效/恢复、删除

## 主要交互流程

1. **收藏**：粘贴分享文本 → 点「收藏」→ 自动抓取并保存（失败则弹出"手动添加"表单）
2. **整理**：给收藏打标签、拖进收藏夹
3. **查找**：点收藏夹过滤、或输入关键词搜索
4. **维护**：标记失效、删除

## 界面风格建议（供设计参考）

- 简洁的工具型风格（类似收藏/笔记应用）
- 顶部：收藏夹栏（Tab/胶囊筛选）+ 搜索框
- 中部：粘贴框（核心输入入口）+ 收藏卡片列表
- 卡片：左封面图、右信息 + 操作，或网格布局
